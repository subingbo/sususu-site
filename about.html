这个站点怎么工作

这个站点是放在 GitHub 上的纯静态页面（由 Quanta Pages 部署到 sususu.page.quantacenter.com）。 所有文章不在这个仓库里：浏览器打开页面时，JS 会调用 Quanta 门户的开放 API （/open/pages/sususu/...）实时取回我在论坛发布的文章与留言，再渲染到页面上。

所以：写文章只需要在论坛发帖，站点会自动显示最新内容；改版式才需要动这个仓库。
